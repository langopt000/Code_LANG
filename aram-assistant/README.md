# ARAM 海克斯大乱斗实时助手

给英雄联盟海克斯大乱斗（ARAM Mayhem）用的本地浮窗助手。读取客户端状态与屏幕，实时给出三类信息：

1. **海克斯三选一** — 全局胜率 / 选取率 / 梯队、本英雄搭配胜率与 ±pp、与本阶段排名、卡面说明，按综合分排序。
2. **出装与顺序** — 出门装 → 鞋子 → 第一/二/三件 → 后续成装，随已选海克斯切换专属样本；结合敌方阵容给针对性备选（重伤 / 护甲 / 魔抗 / 穿透）。
3. **实战核对** — 读取己方当前装备，按实际已出的成品数推进「下一件」，排除已买与重复鞋子后列出这一件位胜率最高的 3 个，并提示计划外装备。

数据来自 `aramkit.cn` 同源的公开统计（高分段，日更）。服务只在本机 `127.0.0.1:8765` 运行，不上传任何数据。

## 快速开始

```bat
:: 一键唤起：确保服务在跑，并弹出游戏内置顶浮窗
show_overlay.bat

:: 只看控制台（浏览器里用）
start.bat
```

打开 <http://127.0.0.1:8765/> 是控制台页面；`?overlay=1` 是浮窗形态。

## 文件

| 文件 | 作用 |
|---|---|
| `app.py` | HTTP 服务、状态机、全部 API 与控制动作 |
| `datafeed.py` | ARAMKit 数据客户端：版本发现、磁盘缓存、名称/图标资源 |
| `engine.py` | 推荐引擎：评级打分、海克斯组合协同、出装合并、敌方阵容加权 |
| `league.py` | 客户端（LCU）连接与 Live Client Data 读取 |
| `vision.py` / `ocr.ps1` | 屏幕截取 + Windows OCR 识别海克斯卡牌 |
| `window.py` | 置顶浮窗创建与定位（Edge/Chrome app 模式） |
| `watcher.py` | 守护进程：检测客户端启动，自动拉起服务 |
| `ui/index.html` | 单页界面（控制台 + 浮窗共用） |

零第三方依赖，只用 Python 3 标准库；界面是单文件 HTML/CSS/JS。

## 开机自启（可选）

```bat
setup_autostart.bat      :: 写入当前用户启动项，并立刻拉起守护
remove_autostart.bat     :: 移除
```

自启脚本用 `__ROOT__` 占位符在安装时写入真实路径，项目换目录后重跑一次 `setup_autostart.bat` 即可。
